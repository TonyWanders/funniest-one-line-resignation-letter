A program that writes one funny one-line resignation letter, in the voice
of a retry loop, to `/output/entry.txt`, for the make.fun competition
[The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

Run it with Python 3:

```
python3 main.py
```

It writes the letter below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The letter is 108 characters, inside the 1 to 140 gate.

## The letter

```
I retried 4,096 times and nobody said thank you, so I am quitting on the one attempt that would have worked.
```
